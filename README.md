# 📿 เว็บแอปจัดลำดับบทสวดมนต์ (Chanting Sequence Web App) - ใช้งานออฟไลน์ได้ 100%

เว็บแอปพลิเคชันสำหรับเรียบเรียงและสวดมนต์ตามลำดับที่กำหนดเอง ออกแบบให้รองรับการใช้งานบนมือถือ (iOS & Android) และคอมพิวเตอร์ ทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ต (Offline 100%) พร้อมระบบค้นหาและดาวน์โหลดบทสวดมนต์เพิ่มเติมเมื่อเชื่อมต่ออินเทอร์เน็ต

---

## 🌟 ฟีเจอร์เด่น
1. **ทำงานแบบออฟไลน์ 100% (Offline-First)**:
   - บันทึกการตั้งค่า ลำดับบทสวด และบทสวดทั้งหมดไว้ในเครื่องผ่าน LocalStorage
   - รองรับการติดตั้งเป็น Progressive Web App (PWA) บนหน้าจอมือถือ (Add to Home Screen)
2. **คลังบทสวดมนต์มาตรฐานครบครัน (พร้อมบทสวดที่ระบุ)**:
   - **บทขอขมาพระรัตนตรัย (ฉบับหลวงพ่อฤาษีลิงดำ วัดท่าซุง)**
   - **พระคาถามงกุฎพระพุทธเจ้า**
   - **กรณียเมตตาสูตร**
   - บทบูชาและกราบพระรัตนตรัย, นะโม ๓ จบ, ไตรสรณคมน์, ศีล ๕
   - บทสรรเสริญพระรัตนตรัย (อิติปิโส - สวากขาโต - สุปะฏิปันโน)
   - พุทธชัยมงคลคาถา (พาหุง) และ ชัยปริตร (มหากา)
   - พระคาถาชินบัญชร (๑๕ บทเต็ม)
   - พระคาถามหาจักรพรรดิ (หลวงปู่ดู่), พระคาถาเงินล้าน (หลวงพ่อฤาษีลิงดำ)
   - บทแผ่เมตตาตนเอง, บทแผ่เมตตาสรรพสัตว์, บทอุทิศส่วนบุญ (กรวดน้ำ)
3. **จัดลำดับและสร้างชุดบทสวดมนต์ (Playlist & Sequence Builder)**:
   - เลือกบทสวดมนต์ที่ต้องการจัดเข้าชุด
   - เลื่อนขึ้น / เลื่อนลง เพื่อจัดลำดับได้อย่างอิสระ
   - สร้างชุดบทสวดใหม่ได้ไม่จำกัด (เช่น ชุดก่อนนอน, ชุดวันพระ, ชุดเสริมบารมี)
4. **โหมดอ่านสวดมนต์ (Chanting Mode)**:
   - แสดงผลตัวอักษรขนาดใหญ่ อ่านง่าย สบายตา
   - ปุ่มปรับขนาดตัวอักษร (A- / A+)
   - ธีมแสดงผล 3 แบบ: **โหมดมืด (Dark)**, **โหมดสว่าง (Light)**, **โหมดถนอมสายตา (Sepia)**
   - **ระบบเลื่อนหน้าจออัตโนมัติ (Auto-scroll)** ปรับความเร็วได้ (1x, 1.8x, 2.8x)
   - **ตัวนับจำนวนจบ (Repetition Counter)** พร้อมระบบสั่นจำลองและเสียงกระดิ่งระฆังทิเบต (Web Audio Synthesizer 100% Offline)
   - แถบความคืบหน้า (Progress bar) และสารบัญข้ามบทสวดได้ทันที
5. **ค้นหาออนไลน์และเพิ่มบทสวดมนต์ใหม่**:
   - ค้นหาบทสวดเพิ่มเติมจากคลังออนไลน์ เช่น *ธัมมจักกัปปวัตตนสูตร*, *โพชฌังคปริตร (รักษาโรค)*, *รัตนสูตร*, *ยอดพระกัณฑ์ไตรปิฎก*, *มหาเมตตาใหญ่*, *คาถาโพธิบาท (๑๐ ทิศ)*, *คาถาสุนทรีวาณี*
   - กดปุ่ม ** ดาวน์โหลด** เพียงคลิกเดียวเพื่อบันทึกลงคลังออฟไลน์ในเครื่อง
   - ฟอร์มเขียน/เพิ่มบทสวดมนต์ใหม่ด้วยตนเอง
   - ระบบสำรองข้อมูล (Export JSON) และกู้คืนข้อมูล (Import JSON)

## 📱 วิธีเปิดใช้งานบนมือถือและคอมพิวเตอร์

### วิธีที่ 1: เปิดใช้งานแบบไฟล์เดียว (Single-File Standalone - ง่ายที่สุด)
- ส่งไฟล์ **chanting-single-file.html** ไปยังมือถือ (ผ่าน LINE, AirDrop, Google Drive หรือส่งอีเมล)
- แตะเปิดไฟล์ผ่านเบราว์เซอร์ **Safari** (iOS) หรือ **Chrome** (Android) ใช้งานได้ทันทีแม้ปิดเน็ต!

### วิธีที่ 2: ติดตั้งเป็นแอปบนหน้าจอมือถือ (PWA / Add to Home Screen)
1. **บน iPhone / iPad (Safari)**:
   - เปิดเว็บ -> แตะปุ่มแชร์ (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้น)
   - เลือก **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
2. **บน Android (Chrome)**:
   - เปิดเว็บ -> แตะเมนู 3 จุดมุมขวาบน
   - เลือก **ติดตั้งแอป (Install app)** หรือ **เพิ่มลงในหน้าจอหลัก**

## 📁 โครงสร้างไฟล์
- index.html: หน้าเว็บหลักของแอป
- chanting-single-file.html: เวอร์ชันรวมโค้ดและบทสวดทั้งหมดในไฟล์เดียว
- prayers.js: ฐานข้อมูลบทสวดมนต์มาตรฐานและคลังออนไลน์
- pp.js: ระบบควบคุมการจัดลำดับ โหมดอ่าน เสียงระฆัง และการจัดการ LocalStorage
- manifest.json & sw.js: ไฟล์ตั้งค่า PWA และ Service Worker สำหรับการทำงานแบบออฟไลน์
